# B1 Authentication + User Management

## Scope

B1 owns:

- Authentication
- JWT access tokens
- bcrypt password verification
- Authentication middleware
- Role-based access control
- User lookup APIs
- `/api/auth/login`
- `/api/auth/me`
- `/api/auth/logout`
- `/api/users`
- `/api/users/:id`

## Roles

- ADMIN
- COORDINATOR
- VOLUNTEER

## Identity rule

Never trust `userId`, `volunteerId`, `evaluatorId`, or `role` supplied by the client for authorization.

For authenticated requests:

- `req.user.id` is the authenticated user ID.
- `req.user.role` is the current role.

## B2 contract

B2 must expose:

```js
getUserById(id)
getUserByEmail(email)
getUsers()
```

Each user returned to B1 must contain:

```js
{
  id,
  name,
  email,
  passwordHash,
  role,
  domainId
}
```

`passwordHash` is backend-only and must never be returned to the frontend.

## JWT

Algorithm: HS256.

Claims:

- `sub`: user ID
- `role`: role
- `iss`: JWT issuer
- `aud`: JWT audience
- `iat`: issued-at, generated by jsonwebtoken
- `exp`: expiration

The role in the current user record is treated as the source of truth. A mismatch between the current role and the token role invalidates the token in every environment. Production configuration additionally rejects placeholder/weak JWT secrets and caps token lifetime at 24 hours.

## Error contract

```json
{
  "success": false,
  "error": {
    "code": "FORBIDDEN",
    "message": "You do not have permission to access this resource"
  }
}
```

## Security

- JWT secret is environment-only.
- `.env` is ignored by Git.
- Passwords are bcrypt hashes.
- Authentication uses `Authorization: Bearer <token>`.
- Login is rate limited.
- API is rate limited.
- Helmet is enabled.
- CORS allows only the configured frontend origin.
- Password hashes never leave the backend.
- Authentication failures do not reveal whether an email exists.

## Integration

Other backend owners should use:

```js
authenticateUser
requireRole("COORDINATOR")
requireRole("VOLUNTEER")
```

Do not duplicate JWT verification in B3, B4 or B5.
